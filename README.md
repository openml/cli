# OpenML CLI

A command-line interface for OpenML.

## Installation

```bash
pip install -e .
```

## Usage

```bash
# Display help
openml --help

# Display version
openml --version

# Show version information
openml version
```

## Development

### Setup

```bash
# Install with development dependencies
pip install -e ".[dev]"
```

### Running Tests

```bash
pytest
```
